# Trino 0.2.0-dev.1 (development pre-release)

A milestone to pin, not a stable release: formats and APIs may still change before
0.2.0 (see `docs/BACKLOG.md`). Everything listed here passed the full gate set: fmt,
clippy, the workspace tests, the PC GPU tests, and the ares and Azahar self-tests with
their goldens.

## Rendering

- **Local lights per platform tier** (ADR 0010): point and spot lights. The PC native
  profile lights per pixel (highlights, wet surfaces); the 3DS (4 lights) and the N64
  (2) light per vertex.
- **Texture filter per draw and a detail layer** (ADR 0011).
- **3DS GPU vertex T&L** (ADR 0012): static meshes are transformed, lit and projected by
  the PICA200's vertex shader. A scene of about 120 draws went from 19.6 to 5.3 ms of
  ARM11 time per frame in Azahar, and from 30 to 60 fps.
- **N64 text in runs** (ADR 0012): one shim call per run of glyphs, and O(1) glyph lookup
  on every target. UI-heavy N64 frames are 1–2 ms cheaper.

## Two screens and input

- **A typed two-screen API** (`Screen`, `Renderer::on_screen`, `InputState::pointer_on`),
  3D on the 3DS bottom screen, and the castle64 and showcase demos using both screens.
- **Full input coverage:** the whole keyboard (`KeySet`), L2/R2/L3/R3, a right stick and
  analog triggers on every platform that has them, and rebinding of the new keys and
  buttons. `GAME_API_VERSION` 4.

## Tools

- **Real hardware deploys:** `run n64 --device sc64|everdrive` and
  `run 3ds --device network`, with the console's log in the terminal.
- **Project target platforms** in `trino.toml` (`[project] platforms`).
- **A project launcher in the editor:** recent projects, open, and create from a blank
  template or a demo.
- **Honest N64 timing:**
  - `TRINO_N64_TEXT_PAD` measures over code layouts;
  - the emulator harness has an idle limit;
  - the N64 self-test arms a stall watchdog (`TRINO_STALL`).

## Docs

A new README and developer guides (`docs/README.md`). The 2D-only examples are marked
legacy, and a redesigned 2D system is on the roadmap.

## Assets

The editor for Linux, Windows and macOS, the castle64 demo as an N64 ROM (`trino.z64`)
and a 3DS app (`trino.3dsx`), and `SHA256SUMS`. The command-line tooling (`cargo xtask`,
`cargo trino`) runs from an engine checkout, so it ships as source: clone the tag, or
add it as a submodule.
